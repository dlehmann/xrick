# xrick language file: English (default, template for new languages)

# Copy this file to lang/<code>.txt, translate it and start xrick with
# "--lang <code>". Lines starting with # are comments, missing sections
# keep the original texts.
#
# The game font only has A-Z, 0-9, blanks and the marks , . ? so lower case is
# upper cased, umlauts become AE OE UE SS, other characters become blanks.
# Lines are centered by the game.
#
# [intro1]..[intro5]: map intro texts. The first line is the title, then up
# to 11 lines of at most 30 characters (empty lines allowed).
# [gameover], [paused]: one line, at most 23 characters.
# [entername]: one line, at most 30 characters.
# [insertcoin], [credits]: start screen texts in coin mode (--coins), one
# line each, at most 16 and 13 characters. Without coins the insert coin
# text blinks, else the credits text is shown followed by the number of
# coins.
# [world1]..[world4], [worldnumber], [pressfire]: level select screen (a
# secret). World names at most 26 characters; in [worldnumber] the first #
# is replaced by the world, the second by the number of worlds; at most 30
# characters each.
